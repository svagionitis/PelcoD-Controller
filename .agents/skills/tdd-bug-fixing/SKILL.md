# Test-Driven Bug Fixing

Enforce strict Test-Driven Development (TDD) before implementing any bug fix.

## Workflow

1. **Reproduce with a Failing Test:**
   - Do not write or apply the bug fix right away.
   - First write a targeted test that exposes the bug and reproduces the failure.
2. **Observe Failure:**
   - Execute the test suite and confirm that the test fails for the expected reason.
3. **Implement the Fix:**
   - Write the minimal code fix required to resolve the bug according to project standards.
4. **Observe Passing:**
   - Run the test suite and verify that the test passes.
5. **Document Cause and Implications:**
   - Explain what caused the bug, how the fix resolves it, and what the implications of the fix are.
